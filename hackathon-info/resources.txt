# Graph Hacks: Context for AI Agents
Powered by FalkorDB
Agents are only as good as the context they work with. Give yours a graph: connected data it can reason over, a memory it keeps between sessions, and a clear picture of how things relate. Build an agent that makes decisions you can trace.

## Everything you need to build
No graph database experience is assumed. Start with the getting started guide, get FalkorDB running with Docker or Cloud, and keep the Cypher reference open while you build. Stuck on a query or a data model? The FalkorDB Discord <https://discord.com/invite/Y2mMT9VdMy> is the fastest way to an answer, and it is where you find a team too.
